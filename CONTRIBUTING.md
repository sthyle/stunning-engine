Thanks for your interest in contributing to stunning-engine!

Guidelines:
- Open issues for bugs or feature requests before implementing large changes.
- Fork the repository and create feature branches from `Init/structure`.
- Make small, focused commits with clear messages.
- Add tests where appropriate.
- Ensure code is formatted (rustfmt) and passes cargo clippy and cargo test.

Pull requests:
- Target the `Init/structure` branch for initial contributions.
- Describe the change and rationale in the PR description.
